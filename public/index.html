macOS System Files /System, /bin, /usr ✕ NEVER TOUCHED Protected by System Integrity Protection (SIP) and hardcoded application safety rules.

Frequently Asked Questions

Everything you need to know about MacSweeper and how it operates.

How is MacSweeper different from CleanMyMac?

MacSweeper is 100% free, open-source, and has zero subscriptions or telemetry. Unlike proprietary cleaners that use closed black-box algorithms, MacSweeper clearly explains what every file is, why it exists, and allows you to simulate cleanups in Dry Run mode before committing.

How do I restore a file if I need it back?

By default, MacSweeper uses the native macOS Trash API instead of rm -rf. Open the macOS Trash, locate the item, right-click, and select "Put Back". macOS will restore the file to its exact original directory.

Does MacSweeper require Full Disk Access?

MacSweeper works out of the box for standard user caches. However, macOS restricts certain folders (like ~/Library/Safari or Containers) under TCC. Granting Full Disk Access in macOS System Settings allows MacSweeper to detect orphaned containers and browser bloat.

Is MacSweeper available on the Mac App Store?

We provide a direct DMG release for unrestricted native power. An App Store submission package configured for Apple's App Sandbox is currently prepared and under review.
